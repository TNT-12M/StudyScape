学境壁纸图片目录
================

把壁纸图片放在本目录，文件名必须固定为：

  wallpaper-1.jpg
  wallpaper-2.jpg
  wallpaper-3.jpg
  wallpaper-4.jpg

要求：
- JPG 格式（如需 PNG 请改名并同步修改前端常量）
- 建议竖版 1000×2000 或 1200×2400，单张小于 800KB
- 画面主体尽量靠上/居中，避免侧栏文字遮挡重要内容
- 建议带「学境」标识或品牌色（青绿 #316C72）

前端访问路径：/StudyScape/assets/wallpapers/wallpaper-1.jpg（以此类推）

图片缺失时该壁纸选项显示为纯色占位，不会报错。

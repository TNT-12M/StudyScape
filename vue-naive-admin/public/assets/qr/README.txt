学境二维码图片目录
==================

把二维码图片放在本目录，文件名必须固定为：

  微信群二维码      →  wechat-group.png
  公众号二维码      →  official-account.png

要求：
- 正方形 PNG 或 JPG（建议 600×600 以上，文件小于 500KB）
- 不要带过多留白，扫码区域清晰
- 替换图片后重新构建前端才会生效（构建会把 public/assets/ 原样复制到产物根目录）

前端访问路径：/StudyScape/assets/qr/wechat-group.png
              /StudyScape/assets/qr/official-account.png

如果图片缺失，页面会显示「二维码待上传」占位，不会报错。
